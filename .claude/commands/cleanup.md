Use the `cleanup` skill at `.claude/skills/cleanup/SKILL.md`. Its canonical procedure is `.claude/agents/_shared/work-lifecycle.md`; read it once before work. If the skill is unavailable, read that canonical file directly and report the missing entrypoint rather than inventing a parallel workflow.
